    How it works

    1. The page reads your dependency files and asks OSV.dev which advisories affect each exact version. For packages that publish a maintainer desk, it reads the desk's own OSV feed instead.
    2. A maintainer desk is a small static website on the project's own origin. It publishes an agent network that carries the maintainers' notes: when each advisory applies, when it does not, fixes and workarounds.
    3. When you ask, this page's assistant loads that desk's network into your browser, after a card that names the desk's origin. It runs on your key; the desk runs no server and pays for nothing.
    4. The assistant proposes a VEX decision that cites its source. You apply it, and download an OpenVEX file that other tools read.

    Maintainers: make your own desk with the Desk Kit. Demo desks: .

    Triage Desk is a static site: no server, no tracking, no third-party scripts. lanternmd and tidecache are fictional demo projects; every other package and advisory is real data from OSV.dev.
