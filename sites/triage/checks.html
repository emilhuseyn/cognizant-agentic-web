Spec Checks

The Worldwide Agentic Web MVP spec (section 6) asks an implementation to show that bad networks, cycles, budgets and undeclared origins stop with visible errors, and that a partner never gets the visitor's key or private context. These checks run that code here, in your browser.

Checks

Each check calls the runtime function that enforces the rule (from this site's runtime/) and prints the runtime's own message. No AI model and no key are needed; the only requests go to this site's own fixture files.

  • Loading an exact named network from a second origin after approval, and the desk server receiving no key: the live check in the repository (docs/evidence/).
